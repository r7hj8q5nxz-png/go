# 校园信息诊断平台 V0.9

## 项目简介
面向大学生的信息诊断平台，将升学、竞赛信息压缩成诊断卡片，提供快速检索、便捷分享和核心推荐功能，支持状态保持和一键传播，智能时间状态诊断让用户一眼看出轻重缓急，个性化关注功能提升用户粘性，多维数据结构支持多校区、多来源信息管理，**实战级信息库承载 40+条高质量数据**，**建立成都理工信息主权，本校信息优先展示**。

## 数据维护

### 信息诊断数据 (data/diagnosis.js)
遵循以下结构：

```javascript
{
  id: Number,           // 唯一标识
  type: String,         // "升学" | "竞赛" | "关键节点"
  school: String,       // V0.7 新增：学校标识（如："CDUT"）
  title: String,        // 标题
  diagnosis: String,    // 一句话诊断
  action: String,       // 下一步建议
  steps: Array,         // V0.6 新增：具体执行步骤（可选）
  evidence: String,     // 信息依据
  deadline: String,     // 截止日期 (YYYY-MM-DD，必须 >= 2026-01-01)
  targetUser: String,   // V0.5 新增：适合人群（逗号分隔，如："大三, 考研党"）
  sourceUrl: String,    // 官方链接（必须是 http/https 开头）
  sourceKey: Array,     // V0.7 升级：来源标识数组（如：["yz_chsi", "jwc"]）
  priority: Number      // 优先级 (1:高, 2:中, 3:低)
}
```

### 来源定义数据 (data/sources.js)
遵循以下结构：

```javascript
{
  key: String,          // 来源唯一标识
  name: String,         // 来源名称
  domain: String,       // 来源域名
  confidence: String    // 可信度标签（如："官方"、"教育部官方"）
}
```

## 数据校验规则
系统会自动过滤以下无效数据：
- 缺少必需字段（id, type, title, diagnosis, action, evidence, deadline, sourceKey）
- sourceUrl 不是有效的 http/https 链接
- deadline 不是有效的日期格式
- sourceKey 无法在 sources.js 中找到对应来源

## "本周3件事"筛选算法
1. 只选择 priority = 1（高优先级）的信息
2. 按 deadline 升序排序（截止时间最近的优先）
3. 取前 3 条展示

## V0.4 新功能使用说明

### 📤 一键分享本周重点
1. 点击"本周建议"区域右上角的"📤 复制本周重点"按钮
2. 系统自动生成格式化文本并复制到剪贴板
3. 如果是本地文件（file://），不包含链接；如果是网络地址（http/https），自动附带当前页面链接
4. 可直接粘贴到微信群、QQ群进行传播

### 🔗 URL 状态保持
- **使用方式**：点击分类按钮（升学/竞赛/关键节点），URL 会自动更新为 `#type=分类名`
- **分享链接**：复制带 hash 的完整 URL 分享给他人，对方打开后会自动应用相同的筛选
- **刷新保持**：刷新页面后，筛选状态不会丢失
- **示例**：`index.html#type=升学` 会自动展示"升学"分类的内容

### 📋 导出当前清单
1. 使用搜索或分类筛选出目标信息
2. 点击搜索栏旁的"📋 导出清单"按钮
3. 系统将当前显示的所有卡片导出为文本列表
4. 格式：`[截止日期] 标题 - 诊断结论 (原文: url)`
5. 适合班委整理通知、辅导员统计信息使用

### 🔥 智能时间状态诊断（V0.5）
- **自动计算**：系统实时对比当前日期和截止日期，自动显示状态标签
- **四种状态**：
  - 🔥 紧急（红色）：剩余 ≤ 7天，需要立即关注
  - ⚠️ 临近（黄色）：剩余 7-30天，需要开始准备
  - 🕒 充足（绿色）：剩余 > 30天，时间宽裕
  - ⛔ 已过期（灰色）：已截止，自动降权沉底
- **过期处理**：
  - 卡片透明度降低至 60%
  - 标题自动添加删除线
  - 无论优先级如何，自动排到列表最底部
- **受众标签**：每张卡片标题下方显示适合人群（如：大三、考研党、创业者）

### 👥 如何添加受众标签
在 `data/diagnosis.js` 中，为每条数据添加 `targetUser` 字段：
```javascript
targetUser: "大三, 考研党, 成绩优异"
```
系统会自动将其拆分为独立的胶囊标签显示。

## V0.6 新功能使用说明

### ⭐ 关注/收藏功能
**使用方式：**
1. 点击卡片右上角的"☆"图标，变为"⭐"表示已关注
2. 再次点击取消关注
3. 刷新页面后，关注状态依然保持（存储在浏览器 localStorage）
4. "本周建议"区域中，关注的卡片标题前会显示"⭐"

**数据存储：**
- 存储位置：`localStorage['campus_info_starred']`
- 数据格式：`[1, 3, 5]`（关注的卡片 ID 列表）
- 清除数据：清除浏览器缓存或在控制台执行 `localStorage.removeItem('campus_info_starred')`

### 🎯 快捷筛选栏
**三种筛选模式：**
1. **仅看未过期**（默认勾选）：过滤掉已截止的信息
2. **只看关注⭐**：只显示你收藏的信息
3. **只看紧急🔥**：只显示剩余 ≤ 7天的紧急信息

**筛选规则：**
- 筛选之间是"与"（AND）关系
- 例如：同时勾选"升学"分类 + "只看关注" = 显示升学类的关注信息
- 筛选结果实时更新

### 🗑️ 数据硬过滤
**过滤规则：**
- 系统自动过滤截止日期 < 2026-01-01 的所有数据
- 2027年及以后的未来数据正常显示
- 页面底部显示：`已过滤 X 条过时数据`

### 📝 行动清单 (Steps)
**查看步骤：**
1. 点击卡片的"展开详情 ▼"按钮
2. 如果该信息配置了 steps 字段，会在"下一步建议"下方显示具体步骤
3. 每个步骤前有"✓"标记，便于逐项确认

**添加步骤：**
在 `data/diagnosis.js` 中为卡片添加 `steps` 数组：
```javascript
steps: [
    "第一步：登录系统",
    "第二步：上传材料",
    "第三步：在线缴费"
]
```

## V0.9 成都理工信息主权说明

### 🏫 成都理工主权按钮
**位置：** 顶部分类栏最左侧，橙色高亮按钮

**功能特性：**
- **叠加开关**：不与其他分类互斥，可组合使用
- **一键过滤**：点击后只显示 CDUT 校内信息
- **状态保持**：再次点击恢复显示全部信息

**使用场景：**
```
场景1：查看本校升学信息
操作：点击"🏫 成都理工" → 点击"升学"
结果：只显示成都理工的升学信息（9条）

场景2：查看本校紧急事项
操作：点击"🏫 成都理工" → 勾选"只看紧急🔥"
结果：只显示本校的紧急信息

场景3：退出本校模式
操作：再次点击"🏫 成都理工"按钮
结果：恢复显示全部43条信息
```

### 🏷️ 省级信息视觉降权
**标识方式：**
- 非本校信息（school !== "CDUT"）在标题前显示 **[省级]** 标签
- 标签样式：灰色背景，低饱和度颜色，视觉上更轻量

**效果对比：**
- CDUT 信息：`[关键节点] 教材征订截止`
- 省级信息：`[关键节点] [省级] 四川省专升本报名`

### 🥇 CDUT First 排序策略
**排序规则（优先级）：**
1. **状态优先**：过期信息永远排最后
2. **学校优先**：CDUT > SC-PROV（本校信息优先）
3. **原排序规则**：截止时间 或 优先级

**实际效果：**
- 即使省级信息更紧急，同等状态下也优先展示本校信息
- 保证本校学生关注的信息始终在上方
- 省级信息作为补充，排在后面

### 📱 移动端优化
**布局改进：**
- 分类按钮使用 `flex-wrap: nowrap` 和 `overflow-x: auto`
- 按钮过多时支持横向滑动，不会换行
- 隐藏滚动条保持界面美观（但滚动功能正常）

**测试方法：**
1. 按 F12 打开开发者工具
2. 切换到移动设备模式（iPhone/Android）
3. 验证按钮可以横向滑动
4. 页面布局不会崩溃

### 🔄 筛选逻辑说明
**组合筛选示例：**
```
CDUT模式 + 升学分类 + 只看紧急
= 只显示本校的紧急升学信息

= 只显示本校的关注信息
```
